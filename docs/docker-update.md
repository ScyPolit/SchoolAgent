## 更新方式

从零构建遇到软件源下载缓慢，本次改用既有运行镜像：逐项核对根目录生产依赖完全一致，复用 Node.js 24、Chromium、中文字体和现有依赖，装入已经构建验证的完整 LibreChat 产物及新后端。新镜像经过独立检查后，更新原 Compose 应用并重启原代理，继续使用原数据卷、备份卷、HTTP 覆盖配置及两个原有 HTTP 兼容挂载文件。
