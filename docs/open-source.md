# 开源分发说明

首次整理日期：2026-11-04。维护者为 ScyPolit，原创代码采用根目录 MIT 许可；第三方声明见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 完整源码

`upstream/LibreChat/` 以普通目录随仓库分发，包含固定上游基线的全部 7,250 个源文件及校园修改。它不是空的 Git 子模块指针，普通克隆即可获得前端源码。上游独立 Git 历史不随分发上传；基线提交、原始许可、有效锁文件与 61 个修改文件的 LF 归一化哈希分别保留。

根目录和上游各自保留依赖锁文件。根目录下载地址统一为 npm 官方 registry，未变更依赖版本或完整性哈希。

## 提交边界

以下内容不进入公开提交：本机 `.env`、加密密钥、数据库及 WAL、备份、随机 QA 账号、原始运行日志、浏览器会话、代理或编辑器状态、安装目录和构建产物。学校实际应用标识和演示链接已从公开接入文档中移除。

README 截图使用开发测试数据；测试摘要保留在 `docs/`，完整本机诊断文件位于被忽略的 `artifacts/`。公开贡献请继续遵守 [SECURITY.md](../SECURITY.md) 与 [CONTRIBUTING.md](../CONTRIBUTING.md)。
